# Manifesto

Artificial Intelligence has made remarkable progress in image segmentation.

It can recognize objects, predict masks, and generate convincing results within seconds.

Yet professional visual effects artists continue to spend countless hours correcting those results.

The problem is not speed.

The problem is understanding.

---

Current AI systems attempt to decide what should be separated.

Professional artists have already made that decision.

The missing piece is not another segmentation model.

The missing piece is a system that understands the artist's intention.

---

NOVA Layer is built on a different belief.

Artificial Intelligence should not replace artistic judgment.

Artificial Intelligence should amplify artistic judgment.

The artist decides.

The system understands.

The artist confirms.

The system executes.

---

Object separation is not a pixel problem.

It is an understanding problem.

Pixels constantly change.

Objects remain the same.

Hair changes.

Lighting changes.

Motion blur changes.

Occlusion changes.

The physical object still exists.

Professional artists understand this naturally.

NOVA Layer is designed to work the same way.

---

Understanding must always come before precision.

A perfectly refined edge around the wrong object is still wrong.

A rough understanding of the correct object is far more valuable.

For this reason NOVA Layer separates understanding from execution.

First the system proposes.

Then the artist confirms.

Only then does the system perform high-precision analysis.

---

Human guidance is not correction.

It is communication.

Every outline, every keyframe, every structural guide teaches the system something about the intended object.

The artist is not fixing AI mistakes.

The artist is teaching the system how to understand.

---

NOVA Layer does not pursue maximum automation.

Automation without understanding only creates more correction work.

Instead, NOVA Layer pursues maximum production reliability.

Reliable understanding.

Reliable identity.

Reliable precision.

Reliable production results.

---

Artificial Intelligence is exceptionally good at repetitive precision.

Artists are exceptionally good at intention and judgment.

NOVA Layer exists because these strengths are different.

Neither replaces the other.

Together they create something better than either could achieve alone.

---

This is the philosophy behind every feature, every algorithm, every interface, and every workflow inside NOVA Layer.

Whenever a design decision is made, one question should always be asked.

Does this improve object understanding while preserving artistic control?

If the answer is yes, it belongs in NOVA Layer.

If the answer is no, it does not.

---

NOVA Layer is not an automatic rotoscoping tool.

It is an intelligent object understanding system.

Its purpose is not to think instead of artists.

Its purpose is to understand with them.
