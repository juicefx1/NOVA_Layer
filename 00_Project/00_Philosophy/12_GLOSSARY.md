# Purpose

This glossary defines the official terminology used throughout the NOVA Layer project.

All documentation, development, research, and implementation should use these definitions consistently.

---

# Artist

The human creator using NOVA Layer.

The artist defines the intended subject.

AI assists the artist but never replaces artistic judgment.

---

# Artist Intent

Information provided by the artist that communicates which subject should be understood.

Examples include:

- Rough Selection
- Scribble
- Bounding Region
- Previous Smart Layer
- Manual Corrections

Artist Intent guides object understanding.

---

# Evidence

Information extracted from an image or video that helps describe a subject.

Examples include:

- Appearance
- Motion
- Depth
- Structure
- Temporal Information

Evidence supports understanding but does not determine object identity by itself.

---

# Object

The foreground subject that the artist intends to separate from the background.

Typical objects include:

- Person
- Animal
- Clothing worn by the subject
- Hair and fur
- Carried equipment or accessories

By default, NOVA Layer treats the selected subject as a single production unit.

---

# Object Identity

The persistent identity of a confirmed object.

Object Identity remains stable even when appearance changes due to:

- Motion Blur
- Occlusion
- Lighting Changes
- Pose Changes

---

# Object Hypothesis

The system's proposed understanding of the intended object.

An Object Hypothesis is generated before precision extraction and must be confirmed by the artist.

---

# Confirmation

The process in which the artist accepts or refines the Object Hypothesis.

Confirmation establishes a trusted Object Identity.

---

# Smart Layer

A persistent production asset representing a confirmed object.

A Smart Layer stores:

- Object Identity
- Artist Intent
- Extraction Settings
- Production Outputs

It is not merely an alpha mask.

---

# Knowledge

Persistent information accumulated throughout the workflow.

Knowledge may include:

- Artist Intent
- Confirmed Object Identity
- Previous Corrections
- Smart Layer State
- Temporal History

Knowledge supports consistent understanding across frames.

---

# Core Inference Engine

The system responsible for understanding the intended object.

It combines Evidence and Knowledge to generate an Object Hypothesis.

---

# Precision Extraction Engine

The system responsible for generating production-quality extraction after confirmation.

Its responsibility includes:

- Hair
- Fur
- Transparency
- Motion Blur
- Fine Edges

It does not determine object identity.

---

# Production Asset

A persistent asset generated by NOVA Layer.

A Production Asset may contain:

- Alpha
- Foreground RGB
- Metadata
- Extraction Settings
- Future Extensions

Smart Layer is the primary Production Asset.

---

# Workflow

The official NOVA Layer workflow is:

Artist

↓

Artist Intent

↓

Evidence Collection

↓

Object Understanding

↓

Object Hypothesis

↓

Artist Confirmation

↓

Precision Extraction

↓

Smart Layer

↓

Production Asset
